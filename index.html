Patterns & Insights

  • Auth methods: OAuth2 dominates (~60%), API keys common in developer tools.
  • Self‑serve vs gated: CRMs and Ads platforms often gated; productivity and open‑source tools are self‑serve.
  • Common blockers: Contact‑sales gates and missing public APIs.
  • Easy wins: Messaging apps and open‑source CRMs with broad REST APIs.

Agent Workflow

Input apps → Agent script → Docs/API lookup → Extraction → Verification → JSON output → HTML dashboard

Human checks were added for tricky apps (e.g., Salesforce, DealCloud) to confirm accuracy.
